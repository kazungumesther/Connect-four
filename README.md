# Connect Four 

A two-player Connect Four game built with **Next.js, React, TypeScript, and CSS**.

## About the Game

Connect Four is a classic strategy game where two players take turns dropping colored discs into a vertical grid. The goal is to be the first player to connect four discs in a row.

Players can win by connecting four discs:
- Horizontally
- Vertically
- Diagonally

## How to Play

1. Open the game.
2. Players take turns selecting a column to drop their discs.
3. Try to connect four discs of your color.
4. The first player to connect four wins!

## Tech Stack

- Next.js
- React
- TypeScript
- CSS

## Getting Started

Clone the repository:

```bash
git clone https://github.com/kazungumesther/Connect-four.git
```

Navigate into the project:

```bash
cd Connect-four
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Running a Production Build

```bash
npm run build
npm start
```
